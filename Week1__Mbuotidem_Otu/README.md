# ShopSmart Retail Analytics — Week 1

# Project overview

Excel-based retail sales analysis for the AnalystLab Africa Experience Lab Internship Programme.

# Deliverables

ShopSmart_Analysis.xlsx — workbook with source data, formula checks, monthly sales summary, dashboard charts, and business-question answers.

Executive_Dashboard.pdf — KPI summary and key charts.

Business_Report.pdf — business questions, findings, recommendations, risk, opportunity, and methodology.

# Methodology and limitations

Revenue is based on Order_Items.Line_Total. Average order value is total revenue divided by distinct orders. Inventory value is estimated using stock on hand multiplied by product cost price. Supplier-to-product mapping is not explicit in the supplied tables. The dashboard dropdowns are selectors only; connect PivotTable slicers to the charts in Excel to make the filters interactive.
